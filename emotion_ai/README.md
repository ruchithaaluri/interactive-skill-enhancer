# Emotion Recognition using MobileNetV2

## Features

- Transfer Learning using MobileNetV2
- MediaPipe Face Detection
- Real-time Webcam Emotion Recognition
- Seven Emotion Classes
- Fine-tuning Support
- Confusion Matrix
- Classification Report
- Accuracy and Loss Graphs

## Dataset

FER2013

Classes

- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise
